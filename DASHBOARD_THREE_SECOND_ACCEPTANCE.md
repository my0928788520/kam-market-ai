# Three-Second Acceptance Criteria

The first reading path exposes only the supplied direction, confidence, risk,
next workflow state, attention and evaluation time. The same four core values
appear in the Hero and decision cards; raw state, reason codes and source
metadata are excluded from the Hero. Invalid or unavailable data is explicit,
contains no substituted score and preserves the fixed DOM structure.

This is an engineering acceptance contract, not a completed user-research study.
