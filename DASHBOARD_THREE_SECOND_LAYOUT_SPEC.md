# Dashboard Three-Second Layout

The first visible reading path is header, summary hero, then four decision
cards: direction, confidence, risk, and next workflow step. The hero contains
only the provided headline, direction, confidence, risk, workflow state,
attention, evaluation time and display state. It excludes raw states, source
lineage, debug objects and technical engine internals.

Timeframe and module sections remain available below the summary for detail
review. The layout is read-only and formal three-second user testing remains a
future validation activity.
