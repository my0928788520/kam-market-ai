# Replay Non-Trading Boundary — PASS

Replay is offline and read-only. UI output describes state, comparison, confidence, risk, and workflow labels only. It contains no account, order, fill, execution, PnL, position-sizing, or control capability. The only allowed disclaimer phrase is in the footer’s `disclaimer_text`: 「本頁僅供決策規則回放與研究，不構成交易建議。」
