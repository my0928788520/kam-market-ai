# Replay Phase 1 Release Note

Sprint 4 Phase 1 introduces Replay Input Contract, deterministic scenario
timeline, canonical serialization and fixture metadata, all at version `1.0`.
The public package is `kam_market_ai.replay`.

This phase deliberately does not add a Replay Runner, Replay UI, engine call,
Decision integration, market access, network call, quote feed, account,
position, order, transaction simulation or control. Sprint 3 contracts remain
unchanged.
