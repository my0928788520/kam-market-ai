# Replay Phase 2 Release Note

Sprint 4 Phase 2 adds Replay Runner `1.0`, Replay Frame `1.0`, frame
serialization `1.0` and frame fixture metadata names. It generates deterministic
input-only frame chains from a validated static timeline.

No Replay UI, playback controls, chart, API, WebSocket, market feed, account,
position, transaction simulation, PnL, live evaluator or Decision integration
was added. Phase 1 and Sprint 3 contracts remain unchanged.
