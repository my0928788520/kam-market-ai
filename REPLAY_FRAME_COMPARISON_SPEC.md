# Replay Frame Comparison

Version 1.0 compares a current evaluated frame with an optional earlier frame from the same scenario and run. IDs and hashes use canonical SHA-256 content. The initial frame has no invented previous values. Invalid, blocked, or unavailable sources fail closed and retain the fixed four-timeframe/four-module shape.

Scalar changes retain independent confidence and risk deltas. Categorical changes only report availability and equality. No comparison emits transaction language or market advice.
