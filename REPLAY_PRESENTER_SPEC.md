# Replay Presenter Contract

Version 1.0 converts only `ReplayDashboardReadModel` 1.0 into an immutable, template-friendly view. It provides fixed section order, status banner, header, hero, progress, decision, comparison, four timeframe cards, four module cards, messages, footer, and accessibility data.

It does not calculate market state, invoke Engines or Decisions, render HTML, serve routes, connect data, or provide controls. Text is plain escaped text; unavailable values remain unavailable. Differences are descriptive only and do not classify quality or issue transaction instructions.
